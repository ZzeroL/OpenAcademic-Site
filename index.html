形态

CLI + Web 两种运行形态，共用一套 Agent 内核、记忆与上下文管理。

交付

交互单位是条目与决定，不是对话轮次；白卷也是一等交付物。

边界

只做 arXiv、中文界面、私有部署。可以牺牲通用性，不牺牲可靠性。

FIG. 02 · 收 / 核 / 变

它只做三件事

界面为示意1，细节以仓库为准。

01 · 收

一句话派活

不选关键词、不挑论文、不配检索式。它自己检索、下载、按节读，干完的活停在收件箱等你验。

默认 40 轮 · 27 个工具 · 3 层记忆
02 · 核

每条结论带出处

挂 paper_id + 节锚点，点开就是原文高亮句。定位不到就显式标「未定位」，禁止编造节号或引句。

128K 上下文 · 70% / 90% 两档压缩
03 · 变

判断的变更留痕

起草、确认、推翻都进轨迹轴；被推翻的判断带理由变成负样本，同类候选下次自动降级为粗筛。

FIG. 03 · 上手

五分钟，跑起一个实验室

前置条件只有三个：Python ≥ 3.10、Node.js ≥ 20.9、一个 OpenAI 兼容的模型端点。

quickstart · bash
$git clone https://github.com/ZzeroL/OpenAcademic.git
$cd OpenAcademic && python -m venv .venv
$source .venv/bin/activate && pip install -e .
$cd frontend && npm ci && cd ..
$cp .env.example .env# 填 MODEL_URL / MODEL_API_KEY
$node start.mjs
✓ ready → http://localhost:3000
  1. 01
    clone 只是下载代码

    不建库、不建工作区、不写任何配置。

  2. 02
    首次启动才初始化

    建工作区 → 播种技能 → 建库 → 插入管理员。

  3. 03
    服务器部署

    systemd + Nginx；前端产物由 CI 出包，服务器上不编译。

部署后第一件事

初始口令 admin123 公开写在源码里，等同无口令。登录后立即改密，再给组员开账号。
