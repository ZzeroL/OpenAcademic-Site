SHIPPED

从派活到回写，闭环已经能跑。

判断、决定、任务、通道健康与粗筛未读都来自后端；派活会真跑，任务收尾后本周数据整批重取。

  • 收件箱 / 本周清单 / 领域条目流共用一份工作区状态，路由切换不丢操作。
  • 派活落库：tasks + 进程内队列，重启后 queued 自动恢复。
  • agent 发表判断：精读时经 save_item 写入领域，候选态由人确认或推翻。
  • 关键词通道：逐领域跑 arXiv，命中 / 失败 / 限流写 channel_runs。
  • 引用链通道：OpenAlex 前向「本周谁引了种子」与后向「种子引了谁」。
  • 扫描候选：落 scan_candidates，按领域 + 周 + 标识去重，可一键派活。
  • 三标识对齐：arXiv → OpenAlex 实测 100/100，引用链本期做。
  • pytest 覆盖：记忆层、领域容器、上下文回收、工作区模型、通道与 PDF 读取。

GAPS

四个最大的缺口。

这些不是小修小补，决定「读」能不能从 Agent 的工具调用，变成人也能操作的阅读与批注。

01 · READING

阅读页与分级阅读

/p/[projectId]/paper/[paperId] 路由、L1 速览 / L2 精读 / L3 复现、reading_level 可写 UI、原文文档端点、高亮与批注、阅读进度、「精读才入库」门槛都还没有。

02 · LATEX

精确研究工具未注册

8 个基于 LaTeX 源码的精确工具（overview / outline / search / figures / tables / equations / references）写在代码里，但没注册进模型工具表，模型调不到。

03 · WORKSPACE

导入与笔记操作

本地 PDF 导入没有 multipart 端点；领域笔记页只读，没有新建、编辑与反链；跨领域笔记列表与向量召回也还没有。

04 · FRONTEND

搜索、编辑与长会话

会话历史没有全文搜索；笔记没有编辑能力；connect 回放没有分页；长会话的消息导航没有虚拟化。

BEFORE DEPLOY

先改口令，再收窄边界。

内部小团队可以先跑；对公网开放前，至少把这四组事情处理掉。

  • 默认管理员口令首次登录立即改密
  • 账号开通没有注册入口，管理员建号
  • .secret_key备份，不要重新生成
  • 依赖与发布门禁lock 文件 / lint / typecheck

CI 在 GitHub Actions，主仓在 Gitee；需要镜像或自建 runner。

公网前还要补的安全项：Cookie 尚未设 Secure；会话令牌按明文存储；配置密文是 AES-CBC 无 MAC。应补 HTTPS、令牌哈希与 AES-GCM / HMAC。CORS 目前全开，登录也没有失败节流。

VERIFICATION

代码写完了，还没在真实环境里跑过。

这些只能人工跑，按组一次跑完最省事。Agent 主循环、限流、笔记与后端路由目前没有自动化测试。

  • 多用户隔离
  • PDF 真样本页眉过滤
  • 领域 IA 23 条路由
  • 前端 IA：登录 → 交活 → 四态回写
  • 上下文回收 B1–B8
  • 一次真机精读端到端
  • LaTeX 产物与节边界一致性
优先补测：crypto_utils 往返与 mask、load_model_config 合并优先级、AgentState.update_todos 的五种终止路径、run_agent_stream 的事件序列、多会话并发写入与断连续跑。

NOT DOING

这些不是欠债。

  • 每人自带 API Key（BYOK）

  • 统计持久化与历史回溯
  • 会议纪要 / PPT / 外部日历
