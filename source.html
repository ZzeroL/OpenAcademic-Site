SOURCE · APACHE-2.0

把实验室，
装进一台服务器。

Python + FastAPI + Next.js。一个 OpenAI 兼容端点，五分钟跑起自己的研究生产线；论文、笔记与判断都留在你的机器上。

$python -m venv .venv
$source .venv/bin/activate
$pip install -e .
$cd frontend && npm ci && cd ..
$cp .env.example .env# 填 MODEL_NAME / URL / API_KEY

01 · BACKEND

FastAPI + SSE，多人多会话

登录、会话归属、右栏进度与 AG-UI 事件流。Cookie 鉴权，单机 SQLite，不依赖外部服务。

02 · FRONTEND

Next.js 16

收件箱、清单、领域工作台；CopilotKit 接 SSE。

03 · STORAGE

SQLite + Chroma

会话、论文、笔记与向量索引都在工作区目录。

04 · SOURCE

arXiv 全文，OpenAlex 引用

全文只从 arXiv 来；引用链与标识对齐走 OpenAlex。对不上会显式上清单，不猜。

05 · AGENT

按节读，带证据写

模型自己决定下一步；判断经 save_item 发表，候选态等人裁决。

06 · DEPLOY

systemd + Nginx

前端产物由 CI 出包，服务器只跑产物与后端。

QUICKSTART

五分钟，先跑起来。

前置只有 Python ≥ 3.10、Node.js ≥ 20.9，和一个 OpenAI 兼容端点。

  1. 装依赖

    pip install -e .，前端 npm ci。

  2. 填模型端点

    .env 里至少填 MODEL_NAME / MODEL_URL / MODEL_API_KEY。

  3. 启动

    node start.mjs 拉起后端与前端，浏览器打开 3000。

  4. 登录并改密

    初始管理员是公开口令，改完再给组员开账号。

Windows 下激活虚拟环境用 .venv\Scripts\activate，其余命令相同。GitHub 镜像：https://github.com/ZzeroL/OpenAcademic.git。

部署后第一件事：admin@example.com / admin123 写在源码里，等同无口令。登录后立即改密。

DEPLOY

服务器上，只跑产物。

systemd + Nginx；前端由 CI 出包，下载后切换，不在服务器上编译。

  1. 装 unit

    按模板安装 backend / frontend，开自启。

  2. 传前端产物

    CI 出包后 scp 上去，用 release 切换。

  3. 数据放在代码外

    OPENACADEMIC_HOME 指向独立目录。

  4. 备份 .secret_key

    它是解密已存 API Key 的唯一钥匙，不要重生成。

deploy.sh · server
$./deploy.sh startall
$./deploy.sh release /tmp/frontend.tar.gz <sha>
$./deploy.sh healthall ok
$./deploy.sh status
$./deploy.sh rollback
从旧版升级：代码放到新目录，不要覆盖旧目录；.env 里的 IPAPER_ 改成 OPENACADEMIC_，.secret_key 原样复制。完整停机与回滚步骤见部署文档。
