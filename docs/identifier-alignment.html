    01摘要

    本报告验证一件事：给一批真实的 arXiv 论文标识，系统能否稳定找到对应的 OpenAlex work，从而支撑前向 / 后向引用链。

    100样本arXiv 主题检索
    100对齐OpenAlex work
    99DOI 直达首选路径
    1标题兜底唯一匹配

    结论：在当前代理样本上，三标识对齐没有失败案例；但样本不是库内论文，不能直接外推为线上全量对齐率。

    02样本与方法

    • 样本来源：arXiv 主题检索结果，覆盖长上下文大语言模型相关主题。
    • 样本规模：100 篇；不是随机全库抽样。
    • 时间：2026-11-13 执行；结果只代表当日 OpenAlex 状态。
    • 对齐步骤：arXiv id → DOI → OpenAlex work；未命中则规范化标题 + 年份 + 作者做唯一匹配。
    • 判定：只有唯一匹配才算成功；多候选、冲突、无候选都算未对齐。
    为什么用代理样本

    库内论文还很少，直接用库内样本会低估预印本比例。用主题检索构造的代理样本更接近「刚发表、尚未正式出版」的真实输入。

    04兜底路径分析

    标题兜底不是「相似度最高就选」。本报告采用的约束：

    1. 标题规范化：去空白、统一大小写、去除 LaTeX 命令与标点差异。
    2. 年份必须一致；预印本年份与出版年份冲突时不采用。
    3. 作者集合需有交集；完全无交集不采用。
    4. 候选唯一才采用；两个以上候选直接判未对齐。

    这组约束牺牲了一部分召回，换取误配率。对引用链来说，错配比未对齐更糟：错配会把引用关系挂到另一篇论文上，而且很难被发现。

    05为什么不是 Crossref

    arXiv 预印本在 Crossref 没有 10.48550 记录，直接按 DOI 查引用链会大面积落空。Crossref 的引用关系也更偏正式出版渠道。

    OpenAlex 同时覆盖预印本与正式出版，并提供 work 级引用列表，因此成为引用链的主数据源。这不代表 Crossref 无用；正式出版物的 DOI 校验仍可后续接入。

    口径提醒

    「OpenAlex 100/100」只指标识对齐，不指引用列表完整。对齐成功不代表前向 / 后向引用一定完整，二者需要分开评估。

    06限制

    • 样本非随机：主题检索样本偏向热门主题，可能高估对齐率。
    • 时间快照：OpenAlex 数据每日变化；2026-11-13 的结果不能保证复现。
    • 单一数据源：只测 OpenAlex，未对比 Semantic Scholar / PubMed。
    • 未覆盖库内论文：库内论文的标识质量、版本更替未纳入。

    后续应补：库内论文全量对齐、多源交叉验证、错配人工抽检。这些属于验证债的一部分。

    07如何复现

    1. 用相同主题与检索窗口拉取 arXiv 样本，记录检索式与时间。
    2. 对每篇记录 arXiv id、标题、年份、作者集合。
    3. 先跑 DOI 直达；未命中再跑标题兜底，严格按唯一匹配判定。
    4. 输出三列：DOI 直达、标题兜底、未对齐；未对齐附原因。
    5. 与本次报告对比时，同时对比样本构成，而不只是对齐率。
